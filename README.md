## 三条典型使用路径

1. **"我该遵守/采用哪个标准?"** → [选型决策树](knowledge/05-映射与选型/02-选型决策树.md) → 需要细节再进对应标准文件。
2. **"我要写 A 股可持续发展报告"** → [三大交易所总览](knowledge/01-三大交易所/01-总览与时间表.md) → [议题与指标清单](knowledge/01-三大交易所/06-议题与指标清单.md) → [编制全流程](knowledge/06-编制实务/01-编制全流程.md)。
3. **"某个概念/指标怎么披露?"(如范围三、双重重要性)** → [术语表](knowledge/00-标准全景/04-核心术语表.md) → [议题级互映射表](knowledge/05-映射与选型/01-议题级互映射表.md) 看各标准如何要求同一议题。

## 文件模板与阅读约定

每个知识文件遵循统一模板:
**一句话定位 → 适用对象与强制力 → 结构与关键条款 → 核心定义 → 速查表 → 常见误区 → 官方来源**。

- 文件头部有一行元数据(编号、版本、核实日期、对应标准版本)。
- 正文中 `【强制】`/`【鼓励】`/`【过渡期】` 表示要求的性质;金额、日期、比例均为标准原文要求,推断内容会注明"推断"。
- 每份文件末尾"官方来源"给出可核查的原始出处;核实状态统一汇总在 [sources/sources.md](sources/sources.md)。

## 引用规范(AI 使用本库时)

回答中引用知识库内容时,应注明:`标准名 + 条款/章节 + 知识库文件相对路径`。知识库未覆盖的内容,应明确说"未收录",并指向官方来源,不得凭记忆编造条款号。

## 更新监测入口(官方)

| 标准 | 官方入口 | 监测什么 |
|---|---|---|
| 三大交易所指引/编制指南 | [上交所](https://www.sse.com.cn)(规则→上市公司管理)、[深交所](https://www.szse.cn)(法规规则)、[北交所](https://www.bse.cn)(业务规则) | 新议题编制指南、修订、问答 |
| 财政部企业可持续披露准则 | [财政部会计司](http://kjs.mof.gov.cn) | 气候准则正式稿、后续具体准则 |
| ISSB / IFRS S1、S2 | [IFRS Navigator](https://www.ifrs.org/issued-standards/ifrs-sustainability-standards-navigator/) | 修订、辖区采用指南 |
| SASB | [SASB Standards](https://sasb.ifrs.org/standards/) | 行业标准维护更新 |
| GRI | [GRI Standards](https://www.globalreporting.org/standards/) | 新议题/行业标准、生效日期 |

## 配套组件

- **esg-standards skill**:安装到本机用户级目录(`~/.agents/skills/esg-standards/`,Windows 即 `%USERPROFILE%\.agents\skills\`),任意工作区对话中涉及 ESG 披露标准时自动触发,按路由表查阅本库;源文件在 `skill-esg-standards/`(安装与同步方法见该目录 README)。
- **indexes/**:机器可读索引(JSON),知识库的元数据底座。
- **esg-kb MCP 服务器**:已注册到 ZCode 用户级配置(`~/.zcode/cli/config.json`),提供 `esg_search` / `esg_get` / `esg_compare` / `esg_industry` 四个检索工具,新会话自动连接(详见 [mcp/README.md](mcp/README.md))。
- **PLAN.md**:项目计划与范围。
