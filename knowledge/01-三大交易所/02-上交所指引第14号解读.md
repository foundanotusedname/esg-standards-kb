## 三、披露原则(第一章核心)

| 原则 | 要求要点 |
|---|---|
| **双重重要性** | 财务重要性 或 影响重要性,任一成立即须披露(定义见[总览](01-总览与时间表.md#四三所指引的共同框架一致的部分约占-95)) |
| 量化与前瞻性 | 重要性议题应尽量定量;鼓励披露前瞻性信息(目标、计划、情景) |
| 利益相关方沟通 | 议题识别过程中应开展利益相关方沟通并说明方式 |
| 完整与可验证 | 披露口径一致、可验证,不得选择性披露、误导性陈述 |

## 四、每个议题怎么报:四要素框架

对每一个评估为"重要性"的议题,按以下四要素披露(源自 TCFD/ISSB 四支柱):

1. **治理**:董事会与管理层在相关议题上的架构、职责、监督机制;
2. **战略**:议题对公司的实际/潜在影响、对商业模式与财务的影响、韧性(气候议题需情景分析);
3. **影响、风险和机遇管理**:识别、评估、排序与应对的流程及嵌入公司风险管理体系的方式;
4. **指标与目标**:衡量指标及目标设定、进展;气候议题中范围 1/2 排放【强制】、范围 3【鼓励】。

## 五、豁免与过渡期安排

| 机制 | 内容 |
|---|---|
| 重要性豁免 | 评估后不具双重重要性的议题可不披露,但应说明评估结论与理由 |
| 涉密豁免 | 涉及国家秘密、商业秘密的内容可豁免,需说明 |
| 数据暂缓 | 首个报告期相关指标数据确难取得的,可暂不披露,但需说明原因与计划 |
| 鉴证 | 鼓励聘请第三方对报告鉴证或审验【鼓励,非强制】 |
| 差错更正 | 报告存在重要错报的,应当及时更正并披露 |

## 六、与国际标准的衔接

- 气候议题章节实质对接 ISSB 四支柱(对应 IFRS S2),支持沿用其方法(情景分析、转型计划等);
- 鼓励在报告中提供与 GRI、ISSB 等标准的**指标索引**,方便"一份报告、多框架对齐";
- 映射关系见[议题级互映射表](../05-映射与选型/01-议题级互映射表.md)。

## 七、常见误区

1. **把 21 个议题全部照抄一遍** — 只需对**重要性议题**做四要素披露,非重要性议题说明评估结论即可。
2. **忽略"过程披露"** — 指引要求披露议题识别与重要性的评估过程/方法,这是与旧 CSR 报告最大的差别之一。
3. **范围 3 焦虑** — 首版要求下范围 3 仅为鼓励披露,且有数据暂缓机制;先把范围 1/2 与治理机制做实。
4. **以为自愿披露无约束** — 自愿披露主体同样适用指引,且应保持持续披露。
