# 标准选型决策树

> 编号 05-02 · 版本 v1.0 · 编写/核实 2026-09-08 · 前置:[议题级互映射表](01-议题级互映射表.md) · 来源见 [sources/sources.md](../../sources/sources.md)

**一句话定位**:从"你的处境"出发,5 个问题定下"用哪套标准、怎么组合",并给出对应的报告骨架建议。

---

## 一、决策树(依次回答)

```
Q1 你在哪里受监管?
├─ A 股上市(强制主体:指数样本/境内外同时上市)
│     → 骨架 = 三大交易所指引【强制】;方法 = 编制指南第1、2号
│     → 自愿披露主体同样建议用指引做骨架(成本最低的"行业基准语言")
├─ 港股上市
│     → 港交所 ESG 守则【气候强制】+ IFRS S2 对齐;可加 GRI 对齐供应链
├─ 境外上市(欧/美等)
│     → 属地规则优先(如 ESRS/CSRD、加州规则);ISSB 作全球基线
└─ 未上市(发债/供应链压力/评级)
      → Q2
```

```
Q2 主要读者是谁?
├─ 投资者/债权资本 → IFRS S1+S2(基线)+ SASB(行业指标)
├─ 监管(未来财政部体系)→ 基本准则 + 气候准则(征求意见)
├─ 大客户供应链 / NGO / 社区 → GRI(影响披露)+ CDP 问卷
└─ 全都要 → Q3 组合策略
```

```
Q3 预算与数据能力?
├─ 首年/资源有限 → "最小可用组合"(见三)
└─ 能力成熟 → "一份报告、多框架对齐"(见三)
```

## 三、两种成熟组合模式

**模式 A:最小可用组合(首年,资源有限)**
1. 骨架:交易所指引(议题清单 + 四要素);
2. 气候:范围 1/2 先行(范围 3 用过渡缓释),定性情景分析起步;
3. 指标:SASB 本行业 5-10 个可得性最好的指标;
4. 收尾:一页"对齐索引表"(见四)。

**模式 B:一份报告、多框架对齐(成熟期)**
1. 骨架:属地强制规则;
2. 双重重要性评估(GRI 3-1 方法 + 编制指南第 1 号)一次做完,产出两套口径的议题结论(财务/影响);
3. 气候:IFRS S2 口径编制,GRI 102 用参照表回填;
4. 指标:统一数据字典,一次采集、多处标注(SASB 编号 + GRI 编号 + 指引条款);
5. 索引:报告末尾对齐索引表 + 引用官方互操作文件。

## 五、负面清单(组合中的常见错误)

1. **骨架错位**:用 GRI 结构应付交易所强制披露(缺四要素与议题评估过程)。
2. **口径漂移**:同一指标在不同章节数字不一致(能耗/排放边界未统一)。
3. **索引造假**:宣称对齐某框架但缺关键披露项——按 GRI 口径只能声明"参考"。
4. **只报亮点**:违反平衡性原则(负面信息同样必须披露)。
