## 适用性

**Q1 我是不是强制披露主体?**
你是下列之一即为强制:上证 180 / 科创 50 / 深证 100 / 创业板指 / 北证 50 指数样本公司,或境内外同时上市公司。指数样本按交易所定期调整衔接。
→ [总览与时间表](../01-三大交易所/01-总览与时间表.md#二强制与自愿的分界)

**Q2 自愿披露后能不能停?**
不宜。指引口径是自愿披露后应保持持续披露;中途停止需充分说明,且影响市场预期。
→ [上交所解读·豁免与过渡](../01-三大交易所/02-上交所指引第14号解读.md#五豁免与过渡期安排)

**Q3 首年数据不全怎么办?**
可用过渡安排:相关指标确难取得的,暂不披露但需说明原因与改进计划;范围 3 首年鼓励而非强制。
→ [上交所解读·豁免](../01-三大交易所/02-上交所指引第14号解读.md#五豁免与过渡期安排) · [IFRS S2·过渡缓释](../02-ISSB/02-IFRS-S2解读.md#三过渡缓释首年)

**Q4 北交所公司要不要做?**
北证 50 样本公司强制;其他公司自愿。中小企业可从治理类 4 议题 + 气候议题起步。
→ [北交所解读](../01-三大交易所/04-北交所指引第11号解读.md)

## 编制方法

**Q5 重要性议题由谁确认?**
评估由工作组执行,结论应由董事会或专门委员会层面确认;评估方法与理由需在报告中披露。
→ [编制全流程·阶段 3](01-编制全流程.md#阶段-3双重重要性评估4-6-周--整个流程的心脏)

**Q6 涉及商业秘密怎么处理?**
可豁免披露,但需说明;不得以涉密为名规避可验证的重要信息。
→ [上交所解读·豁免](../01-三大交易所/02-上交所指引第14号解读.md#五豁免与过渡期安排)

**Q7 范围 3 要不要算?**
三所指引:鼓励;IFRS S2:强制但首年缓释。建议:先算范围 1/2 并建因子库,范围 3 按类别重要性逐年覆盖(差旅、通勤、外购电力上游是最常见起点)。
→ [IFRS S2·指标与目标](../02-ISSB/02-IFRS-S2解读.md#4-指标与目标)

**Q8 情景分析要定量吗?**
不强制一步到位;可定性起步,但须披露所用情景、方法与结论,并逐步提高定量程度。
→ [IFRS S2·战略](../02-ISSB/02-IFRS-S2解读.md#2-战略)

## 结构与形式

**Q9 报告可以并入年报吗?**
可以单独发布或纳入年报,时间上与年报衔接(不早于年报,最晚次年 4 月 30 日)。
→ [总览与时间表](../01-三大交易所/01-总览与时间表.md#三时间表记住三个日期)

**Q10 和 CSR 报告有什么区别?**
区别在:需披露议题识别与评估**过程**、按四要素结构化披露、定量与可验证要求、豁免需说明理由。CSR 宣传册式的报告不满足指引。
→ [对比矩阵](../00-标准全景/02-对比矩阵.md#四重要性什么是必须披露的四种口径)

**Q11 GRI / ISSB 索引怎么标?**
在报告末尾做对齐索引表:指引条款 ↔ IFRS S2/S1 ↔ GRI 披露项编号 ↔ SASB 指标编号 ↔ 报告页码;引用官方互操作映射,不满足全部要求时声明"参考"而非"按 GRI 编制"。
→ [选型决策树·索引模板](../05-映射与选型/02-选型决策树.md#四对齐索引表模板) · [GRI 体系总览](../04-GRI/01-体系总览.md#三按-gri-编制-vs-参考-gri)

## 数据与责任

**Q12 报告边界怎么定?**
通常与合并财务报表范围一致;影响类披露(GRI 视角)可能延伸至供应链。边界口径需在报告中说明。
→ [互映射表·框架级要素](../05-映射与选型/01-议题级互映射表.md#二框架级非议题要素映射)

**Q13 报告需要审计或鉴证吗?**
指引为"鼓励";上市规则或后续规则可能加码。建议首年建立内控与内部复核,第二年考虑有限保证鉴证。
→ [对比矩阵·鉴证](../00-标准全景/02-对比矩阵.md#二结构与内容对比)

**Q14 发现披露错误怎么办?**
重要错报应及时更正并披露(类似财务信息的差错更正逻辑)。
→ [上交所解读·豁免与过渡](../01-三大交易所/02-上交所指引第14号解读.md#五豁免与过渡期安排)

**Q15 什么时候开始准备下一年度?**
建议 Q1 披露当年报告后即启动:Q2 更新重要性评估、Q3 数据与核算、Q4 撰写,次年 Q1 审议披露。
→ [编制全流程·年度日历](01-编制全流程.md#二年度日历以-12-月-31-日截止财年为例)
