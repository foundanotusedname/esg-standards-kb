# 可持续发展报告编制全流程

> 编号 06-01 · 版本 v1.0 · 编写/核实 2026-09-08 · 方法依据:三所编制指南第 1 号《总体要求》+ 编制实务通行做法 · 来源见 [sources/sources.md](../../sources/sources.md)

**一句话定位**:从零开始写一份三所指引合规报告的完整流程——8 个阶段、年度日历、分工与常见坑。

---

## 一、八个阶段(每阶段:做什么 → 产出什么)

### 阶段 1:启动与治理搭建(1-2 周)
- 董事会/专门委员会明确监督职责;指定牵头部门(通常董办/战略),组建跨部门工作组(财务、HR、EHS、采购、IT、法务)。
- **产出**:治理架构说明(即报告里"治理"要素的素材)、制度性文件(如《可持续发展信息披露管理制度》)。

### 阶段 2:数据与口径盘点(2-4 周,与阶段 3 可并行)
- 盘点可披露数据:能耗、水耗、排放、员工、安全、培训、采购、合规记录等;
- 建立数据字典:指标名、口径、边界(合并范围)、来源系统、责任人;
- 不可得指标列入收集计划(首年可用"暂缓+说明"安排)。
- **产出**:指标数据字典(与可用性标注)。

### 阶段 3:双重重要性评估(4-6 周)——整个流程的心脏
按编制指南第 1 号的方法:
1. **识别**议题:从 21 个议题出发,叠加行业议题(SASB/所在行业惯例)与利益相关方关切;
2. **沟通**:内部访谈 + 外部利益相关方(投资者、客户、员工、社区、监管)调研;
3. **评估**:对每个议题分别打分——财务重要性(对商业模式/财务/现金流/融资的影响)与影响重要性(对环境/社会的实际与潜在影响,严重度×可能性×范围×可补救性);
4. **排序与确认**:形成议题矩阵与实质性议题清单,**董事会/专门委员会确认**;
5. **留痕**:评估方法、参与方、结论与理由全部存档(报告需披露,监管会看)。
- **产出**:重要性评估报告 + 议题矩阵(同时服务 GRI 3-1/3-2 与指引四要素)。

### 阶段 4:通用与治理类披露准备(2 周)
- GRI 2 式组织信息:报告边界(2-2)、鉴证安排(2-5)、治理架构(2-9+)、政策承诺(2-23/24)、利益相关方沟通(2-29);
- 指引要求的治理类 4 议题(尽职调查、利益相关方沟通、反贿赂反贪污、反不正当竞争)。
- **产出**:报告的"组织与治理"章节初稿。

### 阶段 5:气候专题(4-8 周,首次编制建议提前启动)
按编制指南第 2 号 + IFRS S2:
1. 气候风险与机遇识别(物理/转型分类,结合行业);
2. 范围 1/2 排放核算【强制】(确定合并口径、排放因子库);范围 3【鼓励,首年可暂缓】;
3. 情景分析:首年可定性,至少含 1.5℃/2℃ 方向,披露方法与结论;
4. 转型计划与减排目标(有则披露,无则说明);
5. 治理与指标目标四要素成文。
- **产出**:气候章节(可直接对标 S2,一稿两用)。

### 阶段 6:其他重要性议题披露(4-6 周,可跨期滚动)
- 每个实质性议题按四要素:治理 / 战略 / 影响·风险·机遇管理 / 指标与目标;
- 数据从数据字典抽取;定量优先,确难定量说明原因;
- 负面信息如实披露(平衡性原则)。
- **产出**:议题章节初稿 + 对齐索引表(指引条款 ↔ IFRS S2 ↔ GRI ↔ SASB)。

### 阶段 7:审议与披露(2-3 周)
- 内部复核(数据交叉验证、法律审核、涉密筛查);
- 董事会(或专门委员会)审议;
- 与年报同步披露,最晚次年 4 月 30 日(强制主体);
- 同步向 GRI 通报(若声明"按 GRI 编制")、更新内容索引。
- **产出**:正式报告 + 索引表 + 审议记录。

### 阶段 8:鉴证与改进(披露后滚动)
- 评估是否引入第三方鉴证【鼓励】(首年可暂缓);
- 收集监管问询、评级、投资者反馈;
- 更新数据字典与议题清单,进入下一年度循环。
- **产出**:改进清单(下年度输入)。

## 二、年度日历(以 12 月 31 日截止财年为例)

| 时间 | 动作 |
|---|---|
| Q1(1-3 月) | 上年度报告披露(4/30 前);启动当年治理与数据计划 |
| Q2(4-6 月) | 重要性评估更新;利益相关方调研 |
| Q3(7-9 月) | 气候核算与情景分析;议题数据收集 |
| Q4(10-12 月) | 报告撰写;内部复核 |
| Q1(次年) | 董事会审议 → 4/30 前披露 → 鉴证评估 |

## 三、分工速查

| 角色 | 职责 |
|---|---|
| 董事会/专门委员会 | 议题清单确认、报告审议、目标审定 |
| 董办/战略(牵头) | 流程管理、指引解读、报告统稿 |
| 财务 | 报告边界、数据口径、财务影响关联 |
| EHS/运营 | 能耗、排放、水、废弃物、安全数据 |
| HR | 员工类议题数据 |
| 采购 | 供应链议题与供应商管理 |
| IT/安全 | 数据安全、隐私议题 |
| 法务/合规 | 合规类议题、涉密审查、错误更正 |

## 四、常见坑(首次编制 Top 5)

1. **议题评估"闭门造车"** — 无利益相关方输入、无董事会确认,报告披露的评估过程经不起追问。
2. **数据口径后补** — 先写文字再找数,导致边界口径前后矛盾;应先定数据字典。
3. **气候章节脱离财务** — 只讲环保不谈财务影响,S2 与指引都要求"对财务报表/经营的影响"。
4. **只有成绩没有问题** — 违反平衡性,评级与媒体反向解读。
5. **索引表虚构对齐** — 宣称对齐 GRI/ISSB 却缺关键披露项;宁可如实标注"参考"。
