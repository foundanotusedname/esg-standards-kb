# IFRS S1《可持续相关财务信息披露一般要求》解读

> 编号 02-01 · 版本 v1.0 · 编写/核实 2026-09-08 · 标准版本:2023-06-26 发布,2024-01-01 或之后开始的年度期间生效 · 来源见 [sources/sources.md](../../sources/sources.md)

**一句话定位**:ISSB 的"总纲"——规定披露可持续相关风险与机遇的通用要求,回答"披露什么范围的信息、按什么原则、放哪里、何时报"。气候之外的议题都由 S1 兜底。

---

## 一、基本信息

| 项目 | 内容 |
|---|---|
| 全称 | IFRS S1 General Requirements for Disclosure of Sustainability-related Financial Information |
| 发布方 | ISSB(IFRS 基金会) |
| 发布 / 生效 | 2023-06-26 发布;2024-01-01 或之后开始的年度报告期间生效 |
| 强制力 | 取决于辖区是否采纳(约 30 个辖区推进中);中国以财政部体系趋同路径对接 |
| 与 S2 关系 | S2 是 S1 之下气候议题的具体化;S1 先用,再加 S2 |

## 二、披露目标(第 1-6 段核心思想)

要求主体披露其在**短期、中期、长期**面临的**可持续相关风险和机遇**中的重要信息,帮助**通用目的财务报告使用者**(投资者、债权人等)评估:
1. 企业价值;
2. 未来现金流的时间、金额与不确定性;
3. 企业对资源(资金、人才、自然)的获取与依赖。

关键定位:与财务报表**同一个使用者、同一个报告期间**——这是 ISSB 体系区别于 GRI 的根本点。

## 三、核心内容:四要素(第 29 段起)

对每一项**重大**的可持续相关风险与机遇,披露:

| 要素 | 披露什么 |
|---|---|
| **治理** | 负责监督的治理机构(董事会、委员会):职责、胜任能力、信息流转、目标挂钩 |
| **战略** | 价值链上当前与预期的财务影响;商业模式与价值链的依赖;转型计划(如有);韧性 |
| **风险管理** | 识别、评估、排序与监测的流程;与整体风险管理体系的整合 |
| **指标与目标** | 衡量风险与机遇的指标(可参照**行业标准**,即 SASB)、目标与进展 |

## 四、关键概念(易被忽视但高频被问)

| 概念 | 要点 |
|---|---|
| **财务重要性** | 信息若省略/错报/模糊,将影响通用目的财务报告使用者的决策(现金流、融资、价值评估) |
| **报告主体** | 与财务报表一致(通常为合并范围);风险与机遇可能源于**价值链**(上下游) |
| **关联性(connectivity)** | 披露风险与机遇对**当期财务报表**的影响(如资产减值、拨备),以及**预期未来**影响;与财务报表附注互引 |
| **报告位置与频率** | 纳入**管理报告(management report)**,与财务报表**同时**、**同期间**发布;允许中期披露 |
| **可比信息** | 披露前期可比数(首年有缓释);信息变化需重述或说明 |
| **证据** | 披露应有合理支持,信息层次:可直接计量 → 合理估计 → 假设 |

## 五、过渡缓释(首年可用)

1. **气候优先**:首个年度期间可只披露气候相关(即只做 S2),其他可持续议题推迟一年;
2. 可比信息:首个年度期间无需披露前期可比数;
3. 后续细节(如"当期财务影响"披露)有额外一年缓释;
4. 辖区可自定义缓释(ISSB 提供 Jurisdictional Guide)。

## 六、常见误区

1. **"S1 会给我一张议题清单"** — 不会。S1 是原则式(所有可持续相关风险与机遇),不列议题;议题识别靠 SASB 行业标准 + 自评,气候看 S2。
2. **"S1 只讲 ESG 非财务内容"** — 恰恰相反,S1 要求披露对**财务报表**的当期影响,与 IFRS 会计准则高度联动。
3. **"影响重要性也在 S1 里"** — 不在。S1 只有财务重要性;影响重要性在 GRI 与三所指引(双重重要性)里。

## 七、与中国的关系

财政部《基本准则(试行)》(财会〔2024〕17号)在披露目标、信息质量特征、四要素框架上与 IFRS S1 高度趋同,可视为"中国版 S1 概念框架";差异主要在辖区实施节奏(2027/2030 两步走)。
