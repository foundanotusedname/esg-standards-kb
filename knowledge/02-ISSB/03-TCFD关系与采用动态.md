# TCFD 关系与 IFRS S1/S2 全球采用动态

> 编号 02-03 · 版本 v1.0 · 编写/核实 2026-09-08 · 来源见 [sources/sources.md](../../sources/sources.md)

**一句话定位**:讲清两件事——TCFD 去哪了(答案:并入 IFRS S2),以及各辖区谁在强制用 ISSB 标准(含中国的对接路径)。

---

## 一、TCFD → IFRS S2:一次"无缝接管"

| 阶段 | 时间 | 事件 |
|---|---|---|
| 诞生 | 2015 | FSB 成立 TCFD(气候相关财务信息披露工作组) |
| 建议 | 2017 | 《气候相关财务信息披露建议》:确立**治理-战略-风险管理-指标与目标**四支柱与跨行业指标 |
| 移交 | 2022-12 宣布,2023 完成 | ISSB 全面吸收 TCFD 框架起草 S2 |
| 收官 | 2023-10 | TCFD 解散,监测职责移交 ISSB;四支柱由 **IFRS S2** 正式承接 |

**实操含义**:
1. 过去按 TCFD 写的报告,结构可直接迁移到 S2;差异主要在三点——**范围 1/2/3 的强制口径**、**与财务报表的关联披露**、**转型计划与资本投向**。
2. 中国三所指引气候章节、港交所气候规定、财政部气候准则(征求意见)均采用四支柱,底层语言已经统一。
3. 再看到"TCFD 对齐/TCFD aligned"字样,可理解为"S2 前身",新报告建议直接对标 S2。

## 二、全球采用地图(截至 2026-09,B/C 级,细节以各辖区为准)

| 辖区 | 状态 |
|---|---|
| 澳大利亚 | 强制气候报告(AASB S2),2025-01-01 起,范围三缓释、鉴证分步推进 |
| 加拿大 | CSDS 1/2(自愿起步,向强制过渡) |
| 巴西 | CBPS 1/2(对齐 ISSB)2026 年生效 |
| 日本 | SSBJ 发布本土准则,采用安排推进中 |
| 中国香港 | 港交所上市规则气候披露对齐 IFRS S2,主板分阶段强制 |
| 英国 | 认可程序进行中(TPT 转型计划框架配套) |
| 欧盟 | 走 CSRD/ESRS 自有体系,但与 ISSB 有互操作指引;2025-2026 拟简化收窄范围 |
| 美国 | SEC 气候规则进展停滞;2025-03 相关支持撤回(C 级),市场转向自愿采用 ISSB/加州规则 |
| 马来西亚、新加坡等 | 发布或征求意见对齐 ISSB 的本土准则 |
| **中国内地** | 不直接采纳 ISSB;财政部《基本准则》《气候(试行)》**趋同** ISSB,交易所指引对接四支柱;制定《中外可持续披露准则趋同》路线(2027/2030) |

ISSB 自我统计:约 30 个辖区正在采纳或使用其标准(2024-2025 口径)。

## 三、ISSB 标准设定动态(2025-2026)

| 时间 | 动态 |
|---|---|
| 2025-04 | ISSB 决定**不做 S1/S2 全面复核**(post-implementation review),改为**针对性修订**;范围三缓释延续 |
| 2025-2026 | 针对性修订项目推进(细节以 ifrs.org 暴露稿为准,C 级);教育材料持续发布(如行业指标、配对指导) |
| 持续 | 与 GRI 的互操作映射维护(见[映射文件](../05-映射与选型/01-议题级互映射表.md)) |

## 四、常见误区

1. **"TCFD 标准还存在,可以继续说按 TCFD 披露"** — TCFD 已解散,权威文本是 IFRS S2;新报告中建议表述为"对齐 IFRS S2(承接 TCFD)"。
2. **"中国会直接强制 IFRS S2"** — 不会;中国走财政部"国家统一准则体系"的趋同路径,交易所指引管上市公司,框架与 S2 对齐但为独立中文文本。
3. **"各国标准都一样,写一份全球通吃"** — 差异在生效时间、范围三与鉴证要求;跨辖区编制以"ISSB 基线 + 辖区加码"来核对。
