# ESG 披露标准发展时间线

> 编号 00-03 · 版本 v1.0 · 编写/核实 2026-09-08 · 配套:来源见 [sources/sources.md](../../sources/sources.md)

**一句话定位**:按时间轴记忆各标准的来龙去脉,理解"为什么今天长这样"。未单独标注核实等级的事实均为多源公开记录(B 级),个别 C 级已注明。

---

## 一、国际线:从自愿倡议到强制基线

| 时间 | 事件 | 意义 |
|---|---|---|
| 1997 | GRI 成立(美国,源于 CERES) | 最早的系统性可持续报告框架 |
| 2011 | SASB 成立 | 把"实质性"按行业拆解 |
| 2015 | 《巴黎协定》、联合国 SDGs、TCFD 成立 | 气候披露成为全球议程 |
| 2016 | GRI Standards 取代 G4 指南 | GRI 进入"标准"时代 |
| 2017 | TCFD 发布《气候相关财务信息披露建议》 | 确立"治理-战略-风险管理-指标与目标"四支柱 |
| 2018 | SASB 发布全部 77 个行业标准 | 行业实质性体系成型 |
| 2021-10 | GRI 通用标准 2021 版发布(2023-01-01 生效) | 引入人权、环境尽职调查 |
| 2021-11 | COP26:IFRS 基金会宣布成立 ISSB | 国际可持续披露走向统一 |
| 2022 | SASB 归入 IFRS 基金会(经 VRF 合并);GRI 12/13 行业标准发布 | 行业指标与 S 系准则开始融合 |
| 2023-06-26 | **IFRS S1、S2 发布** | 全球可持续披露基线确立 |
| 2023-10 | TCFD 解散,监测职责移交 ISSB | 四支柱由 IFRS S2 正式承接 |
| 2024-01-01 | IFRS S1/S2 生效(首个年度期间) | 辖区采纳陆续启动(欧盟、澳、加、港、日等) |
| 2025-04 | ISSB 决定不做全面复核,转向三项针对性修订;范围三缓释延续 | 标准趋稳,重心转向落地 |
| 2025-06-26 | GRI 102《气候变化 2025》发布 | GRI 与 ISSB 互操作的新一代议题标准 |

## 二、中国线:监管驱动,三年成型

| 时间 | 事件 | 意义 |
|---|---|---|
| 2024-02-08 | 三所指引征求意见稿 | A 股 ESG 披露制度化起步 |
| 2024-04-12 | **沪深北《上市公司可持续发展报告指引(试行)》发布** | 中国上市公司首套统一 ESG 披露规则 |
| 2024-05-01 | 指引实施 | 强制主体最迟 2026-04-30 披露 2025 年度报告 |
| 2024-12-17 | 财政部《企业可持续披露准则——基本准则(试行)》(财会〔2024〕17号) | 国家统一准则体系总纲;2027 基本建成、2030 基本健全 |
| 2025-01-17 | 三所《可持续发展报告编制指南(试行)》:第 1 号《总体要求》、第 2 号《应对气候变化》 | 从"要什么"到"怎么做";后续议题指南分步推出 |
| 2025 | 财政部《气候(试行)》征求意见 | 财政部体系首个具体准则 |
| 2026-04-30 | **强制主体首份 2025 年度可持续发展报告截止** | 中国 ESG 披露进入"强制时代"的实际起点 |
| 展望 2027/2030 | 财政部体系"基本建成/基本健全" | 与 ISSB 趋同的中国路径 |

## 三、港台与欧盟(延伸速览)

| 时间 | 事件 |
|---|---|
| 2024 起 | 港交所《上市规则》ESG 守则改革,气候披露对齐 IFRS S2(C 级,细节待核实) |
| 2025-01 | 澳大利亚强制气候报告(AASB S2)生效 |
| 2025-2026 | 欧盟提出 CSRD/ESRS 简化方案,拟将适用范围收窄至千人以上企业(C 级) |
| 2026 | 巴西 CBPS 1/2(对齐 ISSB)生效 |

## 四、三条主线读历史

1. **碎片化 → 收敛**:GRI(2000s)、SASB(2010s)、TCFD(2017)各自为战,2021-2023 年经 ISSB 整合,形成"ISSB 财务基线 + GRI 影响标准"双支柱格局。
2. **自愿 → 强制**:欧盟与中国几乎同步(2024)把 ESG 披露从倡议变成监管要求;交易所成为最主要的执行者。
3. **气候先行**:无论 ISSB(S2)、财政部(气候准则第一顺位)还是 GRI(102),第一条具体准则都选了气候,因为它是可量化、可比、资本定价最需要的部分。
