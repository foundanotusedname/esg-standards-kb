# 标准全景图:一页看懂 ESG 披露标准

> 编号 00-01 · 版本 v1.0 · 编写/核实 2026-09-08 · 配套:来源见 [sources/sources.md](../../sources/sources.md)

**一句话定位**:本页回答"ESG 披露有哪些主流标准、各自是什么角色、我该关心哪一个"。

---

## 一、五套核心标准的一句话画像

| 标准 | 谁 | 它是什么 | 你的第一印象 |
|---|---|---|---|
| **三大交易所《可持续发展报告指引》**(沪深北) | 证券交易所(自律监管) | 中国 A 股上市公司的**监管披露要求**,类似"强制/半强制的 ESG 财报" | 我要合规,先看它 |
| **财政部《企业可持续披露准则——基本准则(试行)》** | 财政部 | 中国**国家统一可持续披露准则体系**的"概念框架/总纲",未来各具体准则的上位依据 | 中国版趋同路线图 |
| **ISSB:IFRS S1 / S2** | IFRS 基金会 ISSB | 全球**资本市场导向**的可持续披露基线(S2 专攻气候),TCFD 的正式承接者 | 投资者要看什么 |
| **GRI Standards** | 全球报告倡议组织(GRI/GSSB) | 全球使用最广的**自愿性报告框架**,关注企业对**环境与社会的影响**(impact) | 我对世界的影响如何披露 |
| **SASB Standards** | ISSB(原 SASB 基金会) | **77 个行业**的实质性议题与指标库,回答"这个行业哪些 ESG 议题真正影响价值" | 行业实质性的查询手册 |

## 二、关系图(一张图记住格局)

```
                    ┌─────────────────────────────┐
                    │        资本市场/投资者视角      │
                    │  IFRS S1(一般可持续)+ S2(气候) │ ←── TCFD 框架并入(2023 起)
                    │        (ISSB, 全球基线)        │
                    └──────┬──────────────┬───────┘
              趋同/借鉴(指标参照)│              │互操作映射(2024-2025)
        ┌──────────────▼───┐   ┌──────▼──────────────┐
        │ 中国监管披露要求     │   │   GRI(影响视角)        │
        │ 三大交易所指引+编制指南│   │ 通用/行业/议题 三层标准  │
        │ 财政部基本准则(总纲)  │   └──────┬──────────────┘
        └──────┬────────────┘            │行业议题选择参考
               │行业指标参照               ▼
               └────────────► SASB 77 行业标准 ◄──────── IFRS S2 指定"行业标准指标"入口
```

三个关键关系,记住即可覆盖 80% 的困惑:

1. **IFRS S2 ← SASB**:S2 要求气候指标"适当参照行业标准",SASB 是官方指定的行业指标库。
2. **IFRS S1/S2 ↔ GRI**:两大体系 2024-2025 建立互操作映射,GRI 新版气候标准(GRI 102)内置与 S2 的参照表;官方口径是"可以用 ISSB 为起点做 GRI 报告"。
3. **三所指引 ← ISSB/GRI**:交易所指引在气候议题上对接 ISSB 四支柱(治理-战略-管理-指标),同时保留影响重要性与中国特色议题(乡村振兴等),普遍支持用编号索引方式与 GRI/ISSB 对齐。

## 三、"我该关心哪个标准"(按身份速查)

| 你的情况 | 主线标准 | 配合参考 |
|---|---|---|
| A 股强制披露主体(指数样本/境内外同时上市) | 三大交易所指引【强制】 | 编制指南、IFRS S2、GRI(对齐索引) |
| A 股自愿披露 | 三大交易所指引(按自愿披露执行) | 编制指南、GRI |
| 港股上市 | 港交所 ESG 守则【强制气候】 | IFRS S2(已对齐)、GRI |
| 需要向国际投资者/评级解释 | IFRS S1 + S2 | SASB(行业指标) |
| 供应链客户/出口市场要求影响披露 | GRI | ESRS(欧盟客户) |
| 想知道"我这个行业重点披露什么" | SASB 对应行业标准 | 三所指引 21 议题、GRI 行业标准 |

## 四、组合使用的主流做法

实践中几乎没有人"只用一套",常见组合是**"一份报告、多框架对齐"**:

- 以**本地监管要求**(如三所指引)确定结构与底线;
- 气候章节按 **IFRS S2** 四支柱展开;
- 议题选择同时做**双重重要性**(财务重要性 → ISSB 系;影响重要性 → GRI);
- 行业指标查 **SASB** 行业标准,索引表中标注"GRI xxx / IFRS S2 xx"实现一次编制、多处对齐。

详见:[议题级互映射表](../05-映射与选型/01-议题级互映射表.md) 与 [选型决策树](../05-映射与选型/02-选型决策树.md)。
