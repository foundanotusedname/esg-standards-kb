# ESG 披露标准知识库(esg-standards)

本地知识库位于 `F:\esg\`,覆盖:三大交易所《可持续发展报告指引》及编制指南、财政部基本准则(背景)、ISSB(IFRS S1/S2)、SASB、GRI、议题映射与编制实务。全部为结构化中文解读,带来源与核实日期(2026-09-08)。

## 核心规则

1. **先查索引,再读文件,然后回答。** 打开 `F:\esg\indexes\kb-index.json`,按用户问题匹配各条目的 `tags` 与 `standards`,读对应文件后再作答。不要凭记忆回答标准细节——知识库内容经过核实,你的记忆可能过时。
2. **引用必须可溯源。** 回答中注明:标准名 + 章节/主题 + 知识库文件相对路径。示例:"强制主体最迟须于 2026-04-30 前披露 2025 年度报告(三大交易所指引,见 knowledge/01-三大交易所/01-总览与时间表.md)"。
3. **未收录就明说。** 知识库没有的内容(如 SASB 逐行业指标明细、监管问答原文、某地方法规),明确回答"知识库未收录",并给出官方入口(见 `F:\esg\sources\sources.md`)或建议联网检索。不要编造条款号、日期或数字。
4. **冲突以官网为准。** 知识库各文件标注了核实等级(A=官网核实/B=多源交叉/C=单一二手来源)。若用户提供的官网文本与知识库不一致,以官网为准,并提醒更新知识库对应文件与 `kb-index.json`。
5. **先定口径再作答。** 涉及重要性时区分口径(财务重要性/影响重要性/双重重要性);涉及指标时注意边界(合并范围、运营控制法/股权比例法);这些差异在 `knowledge/00-标准全景/02-对比矩阵.md` 与 `knowledge/05-映射与选型/01-议题级互映射表.md` 有对照表。

## 回答模式示例

**例 1(适用性判断)** 用户:"我们是深证100样本公司,2026 年必须披露什么?"
→ 读 01-总览与时间表。回答要点:属强制主体;首份《2025 年度可持续发展报告》最迟 2026-04-30 披露;气候章节范围 1/2 强制、范围 3 鼓励;建议按编制指南第 1、2 号执行。引用文件路径。

**例 2(选型)** 用户:"我们要做 ESG 报告,用 GRI 还是交易所指引?"
→ 读 02-选型决策树。先反问/确认监管身份(A股/港股/未上市)与主要读者,再给组合建议(通常"指引做骨架 + GRI 对齐影响披露")。引用文件路径。

**例 3(未收录)** 用户:"软件行业 SASB 具体指标编号有哪些?"
→ 明确说知识库只收录到行业速查级,逐项指标需到 navigator.sasb.ifrs.org 查 Software & IT Services 标准;可先给 knowledge/03-SASB/02-77行业速查索引.md 中的高关注议题方向。不要编造指标编号。

完整示例与反例见 `references/examples.md`。
